# 📚 Трекер прочитанных книг

Простое консольное приложение на Python для ведения личной библиотеки и анализа прочитанных книг.

## ✨ Основные функции
* **Добавление книг**: сохранение автора, названия, оценки (1-5) и даты прочтения.
* **Проверка дубликатов**: система не позволит добавить одну и ту же книгу дважды.
* **Статистика**: расчет среднего рейтинга всех книг и подсчет количества книг по авторам.
* **Удаление**: возможность очистить список от ненужных записей.

## 🚀 Как запустить
1. Убедитесь, что у вас установлен Python 3.x.
2. Склонируйте репозиторий или скачайте файлы.
3. Запустите основной файл через терминал:
   ```bash
   python main.py
   ```

## 📋 Пример работы меню
```text
--- Трекер прочитанных книг ---
1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход
```

## 🛠 Технологии
* **Python 3**
* **JSON** (для хранения базы данных книг)
